Installs the clock firmware on the Waveshare ESP32-S3-Touch-AMOLED-1.75 round display module straight from your browser. No software to install.Waveshare ESP32-S3-Touch-AMOLED-1.75 원형 디스플레이 모듈에 시계 펌웨어를 브라우저에서 바로 설치합니다. 따로 설치할 프로그램은 없습니다.

Before you start시작하기 전에
  • A PC with Chrome or Edge (a phone is not recommended).
  • A USB-C data cable (a charge-only cable will not work).
  • Plug the cable into the display module's own USB-C port, which you reach through the opening on the side of the bezel. The USB-C socket at the back of the base only carries power and cannot be used for installing.
  • Close any serial monitor or other program that uses the board's serial port.
  • Chrome 또는 Edge가 있는 PC (휴대폰은 권장하지 않습니다).
  • USB-C 데이터 케이블 (충전 전용 케이블은 안 됩니다).
  • 케이블은 베젤 옆면 개구부로 닿는 디스플레이 모듈 자체의 USB-C 포트에 꽂습니다. 받침대 뒤쪽 USB-C 소켓은 전원만 연결되어 있어 설치에는 쓸 수 없습니다.
  • 보드의 시리얼 포트를 쓰는 다른 프로그램(시리얼 모니터 등)은 닫아 둡니다.
This browser cannot install firmware. Open this page in Chrome or Edge on a PC.이 브라우저에서는 설치할 수 없습니다. PC의 Chrome 또는 Edge에서 이 페이지를 여세요. Installing only works on an HTTPS page. Open this page from its https:// address.설치는 HTTPS 주소에서만 됩니다. https:// 주소로 이 페이지를 여세요.

Steps설치 순서

  1. Connect the clock's display module to your PC with the USB-C cable.
  2. Click Install firmware and choose the new serial port that appears when you plug the clock in.
  3. If asked, choose whether to erase the device first. For a first install, erasing is recommended; it also removes the saved Wi-Fi and settings. Then confirm and wait until it says the installation is complete. Do not unplug the cable. It can take a few minutes.
  4. The clock restarts and shows a QR code and a Wi-Fi name like FXClock-XXXX.
  1. 시계의 디스플레이 모듈을 USB-C 케이블로 PC에 연결합니다.
  2. 펌웨어 설치를 누르고, 시계를 꽂았을 때 새로 생기는 시리얼 포트를 고릅니다.
  3. 기기를 먼저 지울지 물으면 선택합니다. 처음 설치라면 지우기를 권장하며, 저장된 Wi-Fi와 설정도 같이 지워집니다. 확인한 뒤 설치가 끝났다는 안내가 나올 때까지 기다립니다. 케이블을 뽑지 마세요. 몇 분 걸릴 수 있습니다.
  4. 시계가 다시 시작하고 QR 코드와 FXClock-XXXX 같은 Wi-Fi 이름이 나옵니다.

After the install: set up Wi-Fi설치 뒤: Wi-Fi 설정

  1. Scan the QR code with your phone, or join the Wi-Fi called FXClock-XXXX (no password).
  2. The setup page opens by itself. Choose your router and enter its password (2.4 GHz only). If the page does not open, turn off mobile data and open http://192.168.4.1 in the browser. If the phone says there is no internet, choose to stay connected.
  3. The clock restarts and shows the clock screen. To change the Wi-Fi later, hold the BOOT button for 3 seconds; this erases the saved Wi-Fi and returns to step 1.
  1. 휴대폰으로 QR 코드를 찍거나, Wi-Fi 목록에서 FXClock-XXXX에 연결합니다 (비밀번호 없음).
  2. 설정 창이 저절로 열립니다. 공유기를 고르고 비밀번호를 넣습니다 (2.4GHz만 가능). 창이 안 열리면 모바일 데이터를 끄고 브라우저에 http://192.168.4.1을 입력합니다. "인터넷에 연결되지 않음"이 나오면 연결 유지를 고릅니다.
  3. 시계가 다시 시작해 시계 화면을 보여 줍니다. 나중에 Wi-Fi를 바꾸려면 BOOT 버튼을 3초 누릅니다. 저장된 Wi-Fi가 지워지고 1번으로 돌아갑니다.

Voice control: say "Hi ESP", then within 6 seconds an English command such as page four, show clock, exchange rate or go to sleep. The full list is on the clock's setup page: open http:// followed by the clock's IP address in a browser on the same Wi-Fi (the IP is shown at the bottom of the watch-list screens).음성 조작: "Hi ESP"라고 부른 뒤 6초 안에 page four, show clock, exchange rate, go to sleep 같은 영어 명령을 말합니다. 전체 목록은 시계의 설정 페이지에 있습니다. 같은 Wi-Fi의 브라우저에서 http:// 다음에 시계의 IP 주소를 입력하세요 (IP는 관심 종목 화면 맨 아래에 표시됩니다).

If something goes wrong잘 안 될 때

  • The port list is empty: use a data cable and another USB port. If it still does not show, unplug the cable, hold the BOOT button (the upper button on the side of the clock) while plugging it in, then try again.
  • The install stops or fails: unplug and reconnect, close other programs that use the port, and try again, this time with erasing turned on.
  • No suitable browser: install with a PC tool instead. See README.md (esptool or the Espressif Flash Download Tool) and the files in firmware/.
  • 포트 목록이 비어 있을 때: 데이터 케이블과 다른 USB 포트를 써 보세요. 그래도 안 보이면 케이블을 뽑고, BOOT 버튼(시계 옆면의 위쪽 버튼)을 누른 채로 꽂은 뒤 다시 시도합니다.
  • 설치가 멈추거나 실패할 때: 케이블을 뽑았다 다시 꽂고, 포트를 쓰는 다른 프로그램을 닫은 뒤, 이번에는 지우기를 켜고 다시 시도합니다.
  • 쓸 수 있는 브라우저가 없을 때: PC 도구로 설치합니다. README.md(esptool 또는 Espressif Flash Download Tool)와 firmware/의 파일을 보세요.

Where the data comes from데이터 출처

  • Exchange rates, gold (futures price), stock indices: Yahoo Finance chart data (query1.finance.yahoo.com). If it cannot be reached, the daily reference rates of open.er-api.com are used (exchange rates only).
  • Policy interest rates: BIS statistics (stats.bis.org).
  • Korean and US watch-list prices, news and disclosures: Naver Finance (m.stock.naver.com, api.stock.naver.com).
  • Time: internet time servers (pool.ntp.org, time.google.com).
  • 환율, 금(선물 가격), 주가지수: Yahoo Finance 차트 데이터(query1.finance.yahoo.com). 연결되지 않으면 open.er-api.com의 일일 고시 환율을 씁니다(환율만).
  • 기준금리: BIS 통계(stats.bis.org).
  • 한국·미국 관심 종목 시세, 뉴스, 공시: 네이버 증권(m.stock.naver.com, api.stock.naver.com).
  • 시각: 인터넷 시간 서버(pool.ntp.org, time.google.com).

These are public web addresses, not official or licensed data feeds, and the clock uses them for personal use. The services can change or block them at any time, and their own terms of use apply.
